# Weatherly ☀️🌧️

A sleek, modern weather tracking app built for iOS using SwiftUI.  
Easily search, view, and save your favorite cities to keep track of their weather anytime, anywhere.

---

## 🌍 Features

- 🔍 Search for cities and get real-time weather data
- 💾 Save favorite cities for quick access
- 📊 View detailed weather data including temperature, condition, humidity, and wind
- 🗂️ Persist data using Realm (offline support)
- 🧪 Unit tested weather service integration

---

## 📱 Tech Stack

- **Language**: Swift 5
- **Framework**: SwiftUI or UIKIT
- **Networking**: URLSession
- **JSON Parsing**: Codable
- **Local Database**: Realm Swift
- **API Provider**: [OpenWeatherMap](https://openweathermap.org/api)
